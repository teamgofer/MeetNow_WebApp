Fog of War Map Overlay

Demonstrate the fog of war feature that limits visibility of map markers to a configurable radius around the user's location

About this Feature

The "Fog of War" feature creates a visibility radius around the user's location, hiding all map pins outside that perimeter. This premium feature allows users to focus on nearby locations and gradually discover new areas as they move around.

This demonstration showcases both the standard implementation (non-premium users with fixed radius) and the premium implementation (adjustable radius with a slider control).
