# Archive Directory

This directory contains legacy components, utilities, and other code that is no longer actively used in the application but is being preserved for reference or potential future use.

## Contents

### Components

- **CreateMeetup**: Original standalone meetup creation form component. This has been superseded by the UnifiedMeetupCard component but is preserved for reference.

## Usage Notes

Code in this directory should not be imported or used in the active application. If you need functionality from these components, consider:

1. Examining the newer implementations first
2. Migrating the needed functionality to current components
3. If necessary, moving the component back to the active codebase after thorough testing

## Archiving Process

When archiving code:

1. Move the component/utility to the appropriate subdirectory
2. Include any related files (CSS, tests, etc.)
3. Update this README with information about what was archived and why
4. Ensure the archived code is not being imported anywhere in the active codebase
