Your Configuration

To use Wasabi storage with MeetNow, you need the following configuration:

  • Region: Set in .env as VITE_WASABI_REGION
  • Endpoint: Set in .env as VITE_WASABI_ENDPOINT
  • Bucket Name: Set in .env as VITE_WASABI_BUCKET_NAME
  • Access Key ID: Set in .env as VITE_WASABI_ACCESS_KEY_ID
  • Secret Key: Set in .env as VITE_WASABI_SECRET_ACCESS_KEY
