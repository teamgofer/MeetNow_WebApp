Implementation Example

Here's the CSS and HTML needed to implement these neumorphic navigation icons: 

/* CSS */
.icon-box {
  width: 60px;
  height: 60px;
  border-radius: 12px;
  background: #E0E5EC;
  box-shadow: 
    3px 3px 6px #A3B1C6,
    -3px -3px 6px #FFFFFF;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #6D7587;
  transition: all 0.3s ease;
}

.icon-box:hover {
  color: #4a90e2;
}

.icon-box.active {
  box-shadow: 
    inset 2px 2px 5px #A3B1C6,
    inset -2px -2px 5px #FFFFFF;
  color: #4a90e2;
}

<!-- Home Icon -->
